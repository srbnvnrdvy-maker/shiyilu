# 拾遗录 · 文物拟人战棋

原创文物拟人题材的纯前端网页小游戏：收集文物化灵的「器灵」，进行回合制战棋战斗。
零依赖、零构建，直接用浏览器打开 `index.html` 即可游玩（或任意静态服务器托管）。

## 玩法

- **出征**：两章共 12 个关卡（含 2 场 Boss 战），回合制走格子战斗。
  - 速度决定出手顺序；每回合每名器灵可移动 1 次 + 行动 1 次（普攻 / 技能 / 绝技）。
  - 攻击与受击积攒能量，满 100 释放绝技（带特写演出）。
  - 支持自动战斗与二倍速；障碍物会阻挡移动。
- **器灵**：12 名文物化灵角色（越王勾践剑、曾侯乙编钟、千里江山图……），
  五种职业（游锋 / 铁壁 / 神射 / 方术 / 帷幄），消耗古籍残页升级、信物升星。
- **寻珍**：消耗玉璧寻访器灵，特出 2% / 优异 18% / 常见 80%，十连保底优异以上，
  70 次内必得特出，重复角色转化为升星信物。
- **存档**：进度保存在 localStorage；体力每 5 分钟恢复 1 点。

## 文件结构

```
index.html      页面骨架
css/style.css   水墨描金界面样式
js/data.js      角色 / 敌人 / 关卡数据与数值成长
js/main.js      存档、主界面、关卡选择、角色养成、寻珍
js/battle.js    战棋战斗引擎（寻路 / 技能效果 / AI / 演出）
```
